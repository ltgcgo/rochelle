# Rochelle
> **Warning**
>
> As this module is web-compliant standard ESM, to use on Node.js, a minimal web-compliant shim is required. Please check for the minimal import script from _Fly Leaf_.

🔪 Stream chunk splitting, binary and numeric manipulation.

Documentation available on [JSR](https://jsr.io/@ltgc/rochelle/doc).

Named after Roach (Rochelle) in [Cooking Roach](https://www.fimfiction.net/story/173495) and [A Meal Fit for a King](https://www.fimfiction.net/story/172623) by [Bucking Nonsense](https://www.fimfiction.net/user/165254).
